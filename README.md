# Poker Ledger Web

The web version of the Poker Ledger Reader, so the group can open it on any
phone or laptop. This is the `web-app` branch. It has its own history and holds
no game data. The console app lives on `master`, unchanged, and keeps working
as before.

Work in progress. Step 1 (project setup) and step 2 (ledger math in TypeScript,
matched to the cent against the console app) come first; the website itself is
step 3.
